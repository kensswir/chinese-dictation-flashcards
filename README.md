# Chinese Dictation Flashcards — Lesson 3

Digital flashcards for Year 3 Alternative Chinese dictation, Lesson 3
「今天是八月二十日」.

- **Dictation date:** Tuesday 24 November 2026
- **Words:** 日， 月， 年， 昨天， 今天， 明天， 星期， 生日， 今年， plus bonus 圣诞节
- **How it works:** tap a card to flip it — front shows pinyin and English, back shows the Chinese characters. Mark each word as known or still learning, shuffle the deck, or switch on Dictation Mode (pinyin only — write the characters first, then flip to check).

Open `index.html` in a browser, or visit the GitHub Pages site for this repo. No printing needed — everything is digital.
